# 猜数字游戏项目

这是一个为Python初学者设计的教学项目，通过循序渐进的方式学习Python编程基础。

## 项目结构

- `guess_number.py` - 完整的游戏代码，包含详细注释
- `教案/` - 四课时的教学方案
- `截图/` - 游戏运行演示截图

## 学习内容

### 第一课时：认识程序
- 了解Python基础语法
- 运行第一个Python程序

### 第二课时：循环与判断
- 学习if...else条件判断
- 掌握while循环语句

### 第三课时：次数限制与异常处理
- 添加游戏轮次限制
- 处理用户输入异常

### 第四课时：函数封装与多轮游戏
- 使用函数模块化代码
- 实现多轮游戏逻辑

## 快速开始

```bash
python guess_number.py
```

根据提示输入你的猜测，尝试猜出计算机随机生成的数字！
