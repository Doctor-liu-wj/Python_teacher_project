## 课程内容

### 1. 条件判断 - if...else

条件判断用来根据不同的情况执行不同的代码。

```python
if 条件:
    执行代码块1
else:
    执行代码块2
```

**示例：判断猜测**
```python
if guess < target_number:
    print("太小了")
elif guess > target_number:
    print("太大了")
else:
    print("猜对了")
```

### 2. 循环 - while

while循环用来重复执行某段代码，直到条件不满足为止。

```python
while 条件:
    执行代码块
```

**示例：多次猜测**
```python
attempts = 0
while attempts < 10:
    guess = int(input("请输入你的猜测: "))
    if guess == target_number:
        print("猜对了！")
        break
    attempts = attempts + 1
```

### 3. 循环中的break和continue

- **break**: 立即退出循环
- **continue**: 跳过本次循环，继续下一次

```python
while True:
    guess = int(input("请输入你的猜测: "))
    if guess < 1 or guess > 100:
        print("请输入1-100之间的数字")
        continue  # 跳过，重新输入
    if guess == target_number:
        print("猜对了！")
        break  # 退出循环
```

## 课堂练习

1. 修改程序，使用while循环实现多次猜测
2. 添加尝试次数限制（例如10次）
3. 编写程序，让用户可以连续玩多局游戏

## 代码示例

```python
import random

target_number = random.randint(1, 100)
attempts = 0
max_attempts = 10

while attempts < max_attempts:
    guess = int(input("请输入你的猜测（1-100）: "))
    attempts += 1
    
    if guess < target_number:
        print(f"太小了！已尝试{attempts}次")
    elif guess > target_number:
        print(f"太大了！已尝试{attempts}次")
    else:
        print(f"恭喜你！用{attempts}次猜对了！")
        break

if attempts == max_attempts:
    print(f"游戏结束！正确答案是{target_number}")
```
