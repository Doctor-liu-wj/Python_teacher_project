## 课程内容

### 1. 什么是异常？

异常是程序运行中发生的错误。例如：
- 用户输入的不是数字
- 用户输入的数字超出范围
- 文件不存在

不处理异常会导致程序崩溃。

### 2. try...except语句

try...except用来捕获和处理异常：

```python
try:
    # 可能出错的代码
    guess = int(input("请输入数字: "))
except ValueError:
    # 如果出错，执行这里
    print("请输入一个有效的整数！")
```

### 3. 常见异常类型

| 异常类型 | 说明 | 示例 |
|---------|------|------|
| ValueError | 类型转换错误 | `int("abc")` |
| IndexError | 索引超出范围 | `list[10]` |
| KeyError | 字典键不存在 | `dict['不存在的键']` |
| ZeroDivisionError | 除以零 | `1/0` |
| FileNotFoundError | 文件不存在 | `open('不存在.txt')` |

### 4. 多重异常处理

```python
try:
    guess = int(input("请输入数字: "))
except ValueError:
    print("请输入一个整数！")
except EOFError:
    print("输入已结束")
```

### 5. 输入验证

```python
while True:
    try:
        guess = int(input("请输入1-100之间的数字: "))
        if guess < 1 or guess > 100:
            print("数字超出范围，请重新输入")
            continue
        break  # 输入有效，跳出循环
    except ValueError:
        print("请输入一个有效的整数！")
```

## 完整示例

```python
import random

def play_game():
    target_number = random.randint(1, 100)
    attempts = 0
    max_attempts = 10
    
    print(f"我想了一个1-100之间的数字，你有{max_attempts}次机会")
    
    while attempts < max_attempts:
        try:
            guess = int(input(f"请输入你的猜测（剩余{max_attempts - attempts}次）: "))
            
            # 范围检验
            if guess < 1 or guess > 100:
                print("请输入1-100之间的数字！")
                continue
            
            attempts += 1
            
            # 判断结果
            if guess < target_number:
                print("太小了")
            elif guess > target_number:
                print("太大了")
            else:
                print(f"恭喜你！用{attempts}次猜对了")
                return True
        
        except ValueError:
            print("输入错误，请输入一个整数！")
        except KeyboardInterrupt:
            print("\n游戏已中止")
            return False
    
    print(f"游戏结束！正确答案是{target_number}")
    return False

play_game()
```
