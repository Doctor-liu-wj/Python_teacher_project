# 第一课时：认识程序

## 学习目标
- 了解什么是Python程序
- 学会运行Python程序
- 理解程序的基本结构

## 课程内容

### 1. 什么是程序？
程序是一系列指令的集合，用于告诉计算机做什么。就像食谱告诉你如何做菜一样。

### 2. 什么是Python？
Python是一种编程语言，它的语法简洁易懂，是初学者学习编程的好选择。

### 3. 运行第一个程序

在这个项目中，我们的第一个程序就是猜数字游戏的基础版本：

```python
import random
target_number = random.randint(1, 100)
guess = int(input("请输入你的猜测: "))
if guess == target_number:
    print("恭喜你，猜对了！")
else:
    print("很遗憾，猜错了")
```

### 4. 程序的基本要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 导入模块 | 使用现成的功能 | `import random` |
| 变量 | 存储数据 | `target_number` |
| 函数调用 | 执行功能 | `random.randint()` |
| 输入输出 | 与用户交互 | `input()`, `print()` |
| 条件判断 | 根据条件执行 | `if...else` |
